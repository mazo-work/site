# v4 mocks (reference only)

Source files of the reviewed mocks, exported from the Design canvas "Site mocks: three themes and the parakeet"
(2026-11-23, after Jon's review). They need the canvas runtime to render, and their `/_blob/…` image addresses do not
resolve here: read them for structure and values (sizes, colours, fonts, spacing, motion). The images were the photo in
`src/assets/parakeet.jpg`, a halftone and an X-ray drawn from it, a paper-grain tile and a pixel night-sky tile.
